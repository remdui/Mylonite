# Support

## Where to Get Help

- **Usage questions / setup help**: open a GitHub Discussion (preferred), or a GitHub issue if Discussions are not enabled.
- **Bug reports**: open a GitHub issue using the bug report template.
- **Feature requests**: open a GitHub issue using the feature request template.
- **Security issues**: follow the private reporting process in `SECURITY.md`.

## Before Opening an Issue

- Review `README.md` and `CONTRIBUTING.md`.
- Confirm your issue is reproducible on the latest `main` branch.
- Include logs, configuration context (sanitized), and exact reproduction steps.

## Response Expectations

This project is maintained in spare time. We will do our best to respond quickly,
but response times may vary.
